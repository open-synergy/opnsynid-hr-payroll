# Deactivate Payslip Type

## Pre-Condition

- None.

## Flow

1. Open the **Human Resource > Configuration > Payroll > Types** menu.
2. Select one or more records to deactivate (check the checkbox).
3. Click **Action** > **Archive**.
4. Click **OK** to confirm.

## Post-Condition

- The records are archived and no longer appear in the default list view.
- Deactivated types cannot be selected on new payslips or payslip batches.
- Existing payslips and batches that already use this type are not affected.
